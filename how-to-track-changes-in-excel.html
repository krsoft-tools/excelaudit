How to Check Who Created or Last Edited an Excel File

If you received an Excel file and need to verify who created it or who made the last modifications, native Microsoft Excel provides a few basic built-in tools.

Method 1: Check File Properties in Excel

  1. Open your Excel workbook.
  2. Click on File in the top left menu.
  3. Select the Info tab.
  4. On the right side under Related People, you will see Author and Last Modified By.

Method 2: Check Windows File Metadata

  1. Right-click the Excel file in Windows File Explorer.
  2. Select Properties and switch to the Details tab.
  3. Look for the Origin section to see Authors and Last saved by.
⚠️ Why Native Excel Tracking Fails for Audits:
  • Metadata is easily forged: Anyone can change the user name in Excel options before saving.
  • No Cell History: File properties won't tell you which specific numbers or formulas were modified.
  • Track Changes gets wiped: Shared workbook history frequently corrupts or resets after closing.
